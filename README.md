# [Asbestos Removal Leeds](https://asbestosremoval-leeds.co.uk/)

A static HTML website built for **Yorkshire Asbestos Solutions**, an HSE-licensed asbestos removal contractor based in Bramley, Leeds, serving domestic and commercial clients across West Yorkshire.

---

## About the Website

The site targets the primary keyword **asbestos removal Leeds** and ranks for a range of related local search terms including asbestos surveys, garage roof removal, and contractor searches across West Yorkshire towns.

It was built from scratch with a focus on performance, local SEO, and conversion — designed to generate free quote enquiries and inbound phone calls.

## Tech Stack

- Pure HTML5, CSS3, and vanilla JavaScript — no frameworks or CMS dependencies
- Bootstrap 4 grid for responsive layout
- Font Awesome icons
- Custom dark navy and orange design system
- LocalBusiness schema markup (JSON-LD)
- Sitemap and robots.txt
- Canonical tags on all pages
- Absolute internal URLs throughout

---

## SEO Features

- Keyword-targeted H1 and meta titles on every page
- NeuronWriter-optimised body content
- LocalBusiness structured data schema
- Location pages covering all major West Yorkshire towns
- Internal linking between service and location pages
- Fast load times with no render-blocking resources
- Mobile-first responsive design
